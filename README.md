# 🎓 University Enrollment and Admission System

A web-based system designed to streamline the **student enrollment and admission process**. It allows students to register, submit admission requirements, and enroll online, while administrators can review, approve, and manage student records efficiently.

---

## 👨‍💻 Role
**Lead Developer**

- Designed and implemented the system architecture  
- Integrated frontend and backend using **Next.js** and **Node.js**  
- Managed code merging and version control with **Git and GitHub**  
- Configured and deployed the database using **MongoDB Atlas**

---

## 🚀 Tech Stack
- **Frontend:** Next.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB Atlas  
- **Version Control:** Git & GitHub  

---

## 🔑 Features
- Online student registration and admission  
- Student and admin dashboards  
- Role-based access and authentication  
- Cloud-based database with MongoDB Atlas  
- Responsive and modern UI with Tailwind CSS
